I have identified the cause of the double sidebar issue on the homepage (`/`).

### Analysis

1.  **`src/app/layout.tsx`**: The root layout already renders the `SidebarNavigation` for the `'/'` route via the `layoutRules` configuration (as implemented in the recent refactor).
2.  **`src/app/HomeClient.tsx`**: This component wraps its content in `HomeDesktopLayout`.
3.  **`src/app/HomeDesktopLayout.tsx`**: This component *also* explicitly renders `<SidebarNavigation user={user} />`.

This results in the Sidebar being rendered twice: once by the Root Layout (which is correct and global) and once by the `HomeDesktopLayout` (which is redundant).

### Plan

1.  **Modify `src/app/HomeDesktopLayout.tsx`**:
    *   Remove the import of `SidebarNavigation`.
    *   Remove the `<SidebarNavigation />` component from the JSX.
    *   Simplify the layout to only render the children within the centered container structure, preserving the `feed-main-content` styling for the feed alignment.
    *   Update the styles to remove the gap reserved for the internal sidebar, as the external layout sidebar will now handle the positioning.

2.  **Verify**:
    *   Ensure that `src/app/layout.tsx` is correctly configured to show the sidebar for `/` (it is).
    *   This change will leave a single sidebar managed by the global layout.
